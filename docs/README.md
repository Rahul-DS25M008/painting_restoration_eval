## Supplementary reports

## Current guidance versus historical records

The dated planning sections in the roadmap, evidence audit and design contracts explain decisions at their original dates. Their current summaries identify which stages have since completed. Historical pilot numbers are not current benchmark counts.

Executed notebooks, saved reports, producer manifests, archived PDFs, release packages and checksum-pinned visual validation records retain their original bytes. Older wording in those records is not a current task list. Read it with the current guides, errata and provenance ledger rather than rewriting evidence. The October N36/Zenodo v1.0.0 delivery predates D03/D04; the physical supplement is maintained separately in this repository.

Documentation updates do not rerun experiments, remove recorded qualifications or establish independent reproduction.
